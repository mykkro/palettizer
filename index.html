Palettes for scalar data

Palettizer defines color lookup tables for heightmaps and scientific level or intensity data. A transfer curve maps normalized input intensity to a position in the palette; the resulting 256-color table can be exported for use in another visualization tool.

This is a revival of my older palette-warping experiment. The original Sokoloff palette was included for displaying PET data in an MRI/PET workflow. That background explains the palette's presence here; the current prototype works with ordinary image files and does not read PET, MRI, DICOM or NIfTI volumes.

For a grayscale rendering, dark-to-light values run from 0 to 255. Actual physical units and dataset normalization must be handled by the visualization using the exported table. Color images are converted to luminance. All processing stays in your browser.

Drag interior curve points or use their sliders. Add point splits a segment without changing its mapping; Remove deletes the selected interior point. Endpoints stay fixed. Arrow keys move focused points (Shift for larger steps).

PNG export always uses the mapped image, even while Show original is enabled. Presets save settings, not source pixels.
